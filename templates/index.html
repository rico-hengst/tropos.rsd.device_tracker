Welcome to device tracker

This is a portal to get info about devices in machine-readable json format!

Supported keys: (the | is used to separate the typical examples from CAR and Lidar Teams)

  • device (substring match), eg: device=ms-80|arielle {% set url2 = "?device=ms-80" %}/select{{url2}}
  • class (substring match), eg: class=radiation|lidar|polly|pygeometer (all class keyword of any level) {% set url2 = "?class=poll" %}/select{{url2}}
  • class0 (substring match), eg: class0=lidar|radar|radiation {% set url2 = "?class0=radiation" %}/select{{url2}}
  • locationname (substring match), eg: locationname=melpitz {% set url2 = "?locationname=melpitz" %}/select{{url2}}
  • country (substring match), eg: country=Germany {% set url2 = "?country=Germany" %}/select{{url2}}
  • campaign (substring match), eg: campaign=C3SAR|PS127 {% set url2 = "?campaign=C3SAR" %}/select{{url2}}
  • platform (substring match) provided as list separated by comma eg: platform=LACROS,TARO|Polarstern,OCEANET {% set url2 = "?platform=Polarstern" %}/select{{url2}}
  • date (exact format 2022-01-01T12:00:00Z), provided as list with one or two elements separated by comma eg:
    • find all history records that include following date: date=2026-01-01T12:00:00Z {% set url2 = "?date=2026-01-01T12:00:00Z" %}/select{{url2}}
    • find all history records: ... date=2022-01-01T12:00:00Z&date=2026-03-11T12:00:00Z {% set url2 = "?date=2025-01-01T12:00:00Z&date=2026-01-01T12:00:00Z" %}/select{{url2}}
    • combine date timespan and class: ... {% set url2 = "?date=2023-10-21T14:49:36Z&date=2026-05-01T14:49:36Z&class=radiation"%}/select{{url2}}
